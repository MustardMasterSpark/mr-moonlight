# ELVTR — Multi-Agent AI for Game Development · Class Notes Index

13 sessions attended (Class 0 through Class 12). Two files per class:

- **`ClassNN-summary.md`** — executive summary. Short, for reading. What the session was about, what actually mattered, what it asked you to do.
- **`ClassNN-detailed.md`** — the full extraction, for Claude. Every concept, code pattern, case study and rubric, plus a **"Mr. Moonlight application"** section that says plainly where the session's technique fits an FPS and where it does not.

**Source:** the 13 `.pptx` decks. They are image-only (every slide is a screenshot), so the text here was recovered by OCR. Occasional garbled words are OCR artefacts, not errors in the notes.

> **Scope rule.** These notes are for **coursework only**. They are *not* a source of truth for building Mr. Moonlight — Linear is. Nothing in here should drive a code decision in the Unity project unless it also appears in a Linear issue.

## The grading breakdown — the only slide that decides your grade

From Class 0:

| Weight | Component |
|---|---|
| **50%** | **The game itself** — final playable product quality |
| 20% | AI-driven dev pipeline — multi-agent architecture and automation |
| 10% | Technical quality — code standards and system stability |
| 10% | Presentation & demo |
| 5% | Documentation & architecture |
| 5% | Peer feedback |

> *"The grade reflects the thesis. A sophisticated pipeline that didn't ship a game is a 20."*

**Read that again.** Half the grade is the game. The course itself is telling you that the assignments are not where the points are. Time spent making Mr. Moonlight playable outscores time spent making the homework elegant, at a rate of roughly 2:1.

1. **Class 0:** *"A sophisticated pipeline that didn't ship a game is a 20."*
2. **Class 12:** *"Can a classmate play your game in 2 minutes by clicking a link?"* — that is the gate on Assignment #10, worth up to half the total score.
3. **Class 2:** *"One Agent, One Wow."* Pick the single AI-driven moment that makes the game worth playing, and build the pipeline around that. Everything else is scope creep.
