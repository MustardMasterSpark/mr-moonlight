# Class 0 — Welcome / Orientation · Executive Summary

**One line:** the housekeeping session, but it contains the single most important slide of the whole course — the grading breakdown.

## What happened

Instructor introductions, course structure, the assignment map, environment setup, a breakout session, and a design exercise.

**Instructors:** Joshua Burdick — Localization Automation Engineer at **Epic Games**, building AI tooling for Fortnite and Unreal production pipelines. Avery Shelly — associate instructor.

**Shape of the course:** 14 interactive classes over 7 weeks. Applied engineering, not ML theory. Ten assignments — eight mandatory, two optional — chaining toward one playable game.

## The thing that actually matters

**Grading:**

| Weight | Component |
|---|---|
| **50%** | **The game itself** |
| 20% | AI-driven dev pipeline |
| 10% | Technical quality |
| 10% | Presentation & demo |
| 5% | Documentation & architecture |
| 5% | Peer feedback |

> *"A sophisticated pipeline that didn't ship a game is a 20."*

And: *"Every one of you should ship a playable game. Not a demo. Not a prototype. A game someone can pick up, play, and finish."*

## What it asked you to do

Nothing gradeable. Two exercises: describe the game you've wanted to make in one sentence, and name the one thing that's been hardest to build alone.

## Required tools

Only two things are genuinely required: **access to an LLM** and **a game engine**. Everything else — VS Code, Git, Python, Docker, Ollama — is listed as *recommended, not required*. The slide says outright: *"You can complete this course with just an LLM subscription and a game engine."*

## Takeaway for Mr. Moonlight

You are already past the bar on tooling. The 50% weighting says your instinct — put the hours into the Unity project, not the coursework — is the correct strategy, and the course agrees with you in writing. Keep this slide; it is the justification if anyone asks why the assignments are lean.
