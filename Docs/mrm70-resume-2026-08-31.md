**Where things stand:**
- **10 `TerrainLayer` assets exist and are wired to the live terrain** — one per biome
  (`TL_Biome_Forest`, `AutumnForest`, `EerieForest`, `HereticForest`, `Beach`, `Mountain`,
  `FlakTower`, `Fountain`, `Glade`) plus a dedicated `Path` layer for roads. All under
  `Assets/_Project/Art/Environment/Terrain/ISLAND_TERRAIN_TEXTURES/Layers/`.
- **Beach is already painted** — everywhere at or below sea level + 5m (Y ≤ 13) — 47% of the
  terrain. Don't repaint it by hand; if the band needs to change, it's a one-line height threshold
  in a script, not a manual brush pass.
- **The other 8 biomes + Path are unpainted.** Until they're painted, Gaia's Layer Palette shows
  everything else as `TL_Biome_Forest` by default — that's Unity's own unpainted-terrain fallback
  (layer index 0), not real data. Don't mistake "looks like Forest everywhere" for "Forest is
  painted everywhere."
- **Texture source note:** the diffuse/normal textures wired into these layers are Carlos's own
  curated per-biome images, run through the project's Pixel8r-matching quantiser. An earlier
  attempt this same day used Poly Haven ground textures and separately a Retro Realism
  Dirt/Moss/Rock/Soil set — **neither of those made it into the project**, both superseded. Don't
  reintroduce them by accident.

**What's next:** paint the remaining 8 biome layers + Path onto the terrain, by hand in Gaia's
Layer Palette (Paint Terrain → Paint Texture → pick a layer → brush). Two nesting reminders from
the biome doc: `Fountain` sits inside `EerieForest` and `Glade` sits inside `AutumnForest` — paint
the parent biome first, then the smaller pocket on top. Overlap between them is fine.
