DESCRIPTION (the body field)
============================

Carlos picked 20 unique skies in the Playground Skybox Reviewer and assigned them to the game's acts. This brings them
into Mr. Moonlight under Assets/_Project/Art/Environment/Skies/ so the MRM-86 lighting/weather rework starts with the
assets in place. No game code, scene, prefab, preset or switcher changed; nothing references the new materials, and the
old Environment/Skyboxes/ folder is untouched.

Assets
- 01_Story/: 7 materials (M_Sky_Story_1_Campsite ... 7_Apocalypse).
- 02_Legion/: 20 materials (M_Sky_Legion_W<wave>_A<act>_<Beginning|Conflict|Ending>; wave 7 has only two acts).
- Textures/: 20 sky textures (T_Sky_*), shared by acts that reuse a sky. 7 AllSky PNGs copied with their reviewed
  import settings (fresh GUIDs, vendor AssetOrigin stripped); 12 Ether / custom skies re-rendered as 6-face strip PNGs
  (importer flips faces vertically, so faces were written flipped; verified pixel-exact) imported as BC7 cubemaps; one
  16 px pure-black .cubemap. Nebula Red's yaw 0 / pitch -90 / roll 56 is baked into its texture.
- Every material is Skybox/Cubemap, Tint 0.5, Exposure 1, Rotation 0.
- About 237 MB of new PNG through Git LFS (native .cubemap files would have been 700 MB of hex text, so they are not used).
