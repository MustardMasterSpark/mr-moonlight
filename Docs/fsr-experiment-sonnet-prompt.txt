CURRENT TASK: FSR upscaling spike (curiosity, not scoped for October)
===========================================================================
Carlos asked whether NVIDIA DLSS could run on his AMD RX 9070 XT. It can't — DLSS (any
version) is hardware-locked to NVIDIA Tensor Cores, not a software gate. A third-party
reimplementation exists (github.com/danielblnc/DLSS-NR-on-AMD, active alpha) but it works by
DLL-proxying into specific shipped AAA games' own existing FSR pipelines (Cyberpunk 2077,
GTA V Enhanced, RE Engine titles) one game at a time — it's not an engine plugin and has
nothing to hook into on a Unity project with no FSR implementation. Not applicable here.

The real, relevant path: Unity 6.3's URP already ships **FSR 1.0** and Unity's own **STP**
temporal upscaler as built-in "Upscaling Filter" options on the URP render pipeline asset —
enable Dynamic Resolution Scaling, pick a filter. No third-party SDK, no external package,
runs on any GPU including the 9070 XT.

Tracked as **MRM-78** ("Spike: FSR upscaling in URP (curiosity/experiment)"), branch name
`mrm-78`, in Linear project MrMoonlightDemo. Scope is narrow on purpose: get FSR1 and/or STP
visibly running on the Island scene, compare quality/perf on Carlos's hardware, nothing more.
Do not let this expand into a real shipped feature branch without Carlos explicitly asking —
the whole point was curiosity.
