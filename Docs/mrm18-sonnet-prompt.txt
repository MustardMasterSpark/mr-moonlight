TRAPS TO REMEMBER (already burned time on these once each):
- Play Mode edits to scene GameObjects/components are silently discarded on stop. Asset/material
  edits (SetFloat + SaveAssets) persist fine regardless. Always: confirm
  EditorApplication.isPlaying == false, edit, manage_scene save, then read back fresh to confirm.
- Material.HasProperty() gives false negatives for raw HLSL global array uniforms not registered
  as Shader Graph Blackboard properties (the DRM DATA1/2/3 arrays). Verify with a
  SetVectorArray/GetVectorArray round-trip instead.
- Tool round-trip latency between separate calls can be 15-25+ real seconds — too slow to catch a
  <20s animation across two separate screenshot calls. Either do it in one execute_code call
  (construct/age objects synchronously) or temporarily stretch lifeLength for the screenshot, then
  reset it.
- Assets/ThirdParty/** is entirely git-ignored. Any future vendor package with .cs/.shader/.cginc
  logic (not just binaries) needs to land in Assets/_Project/Code/Vendor/<Package>/ instead, or it
  silently never gets committed.
