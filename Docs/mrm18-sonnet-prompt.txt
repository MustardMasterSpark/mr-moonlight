TRAPS TO REMEMBER (new this session, on top of the ones already in the build-summary doc):
- DRMLiveObjectsPool silently drops new ripples once DRMLiveObjects.Count >= DRMController.count
  — no warning, no error, they just don't appear. If ripples/effects "mostly don't show up,"
  check this cap first.
- The per-count DRM .cginc files (Ripple_8_..., Ripple_200_...) are a purely mechanical
  template — only the array size and the unrolled loop bound change with count. Safe to
  hand-author a new count without the actual Amazing Assets editor tool (which isn't installed
  in this project — only ThirdParty/DynamicRadialMasks/ exists as an empty leftover folder).
- Building a VolumeProfile + VolumeComponent via script needs an explicit
  AssetDatabase.AddObjectToAsset() call for the component before saving, or it silently doesn't
  persist. See CRT section above.
- Moving a vendor .shader file that has relative #include paths means moving every file it
  #includes (transitively) into the same new folder together, or the includes break. Custom
  Editor GUI scripts (CustomEditor "...") are the exception — they're found by class name, not
  path, so they can stay put even when the shader itself moves.
