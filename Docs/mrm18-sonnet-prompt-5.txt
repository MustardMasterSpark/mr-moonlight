TRAPS ALREADY KNOWN IN THIS AREA
===============================================================================
- **Play Mode discards scripted edits on stop** - hit repeatedly this session (rain rate, ripple
  tuner values, needed re-applying more than once). Always confirm `Application.isPlaying == false`
  before an edit you need to persist, and re-verify the value stuck after Carlos stops Play.
- **A file copied into `Assets/_Project/Audio/` via script (not dragged into the Editor) lands on
  the wrong import preset** even with the correct filename prefix - apply the right `Aud_*` preset
  by hand afterward (see `Docs/audio-import-workflow.md`'s own troubleshooting note, now confirmed
  a second time).
- **Deleting a `.cs` file from disk without first removing its component from the scene** leaves a
  dangling "missing script" reference on whatever GameObject had it - caught and fixed once this
  session (`FadeOverlay` had `SplashSequence`'s ghost after its file was deleted). Always check
  `GameObjectUtility.RemoveMonoBehavioursWithMissingScript` or a manual scene sweep after deleting
  a script that's used as a live component, not just a search for remaining code references.
- **URP camera-to-RenderTexture alpha is broken project-wide** (see above) - don't reach for that
  technique for anything new without using difference matting from the start.
- Screen Space - Overlay Canvases always composite after ALL camera rendering (base + any stacked
  overlay cameras) - Camera Stacking does NOT help make something "immune" to a UI element's
  coverage; only a separate, higher-sort-order Canvas can sit visually on top of another Canvas.
