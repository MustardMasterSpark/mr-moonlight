   Carlos is restyling every character's 2D turnaround through Tripo's image models before

   Went through several rounds of real, screenshot-diagnosed failures — this is not
   theoretical, each fix below was found by generating and looking at the actual output:
   - Round 1: arms read short → root cause was posture drift (bent/lowered arms), not
     proportion. Fixed with an explicit T-pose anti-drift clause.
   - Round 2: hands came back 3-fingered despite the prompt already asking for 5. Fixed with
     a dedicated, repeated HAND NOTE.
   - Round 3: arms STILL read short even with a correct T-pose held → root cause was Tripo
     always outputting a SQUARE image while the prompt asked for 4 views side-by-side in one
     wide composition, squeezing the widest feature (the arms). Fixed by splitting into 4
     separate single-view generations (FRONT/LEFT/RIGHT/BACK), each getting the full canvas.
   - Round 4: LEFT/RIGHT views were still showing T-pose arms — turns out Carlos wants the
     lateral views to show arms relaxed DOWN at the sides (a clean profile silhouette), not
     T-pose at all. T-pose is FRONT/BACK only now. Fixed across all templates.

   Current state, believed solid but **NOT YET VALIDATED against a real generation** — the

     1.5 as a last-resort fallback. Nano Banana 2 and Midjourney explicitly NOT recommended
     for the real batch.
   - Enemies get creative liberty on SURFACE detail only (dirt, wear) — hard limit on no new

   - Enemies also carry a "menacing, not just stylized" layer grounded in

     gritty realism) — Carlos's blunt working descriptions of each character were translated
