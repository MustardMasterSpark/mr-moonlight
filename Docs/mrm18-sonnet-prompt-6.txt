TRAPS ALREADY KNOWN IN THIS AREA (unchanged from prompt-5, still true)
===============================================================================
- Play Mode discards scripted edits on stop - confirm Edit Mode before an edit you need to persist,
  re-verify after Carlos stops Play. (Confirmed AGAIN this session, in Playground - stop Play Mode
  before every component edit, every time, no exceptions.)
- A file copied into Assets/_Project/Audio/ via script lands on the wrong import preset - apply the
  right Aud_* preset by hand.
- Deleting a .cs file from disk without removing its component from the scene leaves a dangling
  "missing script" reference - sweep the scene after deleting a script used as a live component.
- URP camera-to-RenderTexture alpha is broken project-wide - use difference matting from the start.
- Screen Space - Overlay Canvases always composite after ALL camera rendering - only a higher-
  sort-order Canvas sits visually on top of another Canvas, Camera Stacking doesn't help.
- **New, general Unity-MCP trap confirmed this session:** editing a component's serialized fields
  does NOT flush to the .unity scene file on disk by itself - an explicit scene save
  (manage_scene action=save) is required, or the edits vanish if the scene is closed/switched
  without saving. Cost about 20 minutes of rework tonight when Carlos switched Playground scenes
  before a save happened. Save the scene explicitly after any batch of component edits you need to
  survive a scene switch, don't rely on it happening implicitly.
