== HOW THE DAILY JOB WORKS ==
  1 login non-interactive (token expired -> toast "Sesión expirada: doble clic en Iniciar sesión.bat", exit)
  2 reads the newest Liked videos; anything not in likes_conocidos is auto-placed by channel (the lists that
    channel's videos usually went to; unknown channel -> 190) and logged as "nuevo_like"
  3 (only with aprobado.flag) walks the lists in id order: creates the playlist if missing (PRIVATE, name
    "NNN <name>", mirror "2NN [Old] <name>" for videos that exist only on the old account), reads the playlist's
    items first (never inserts a duplicate), inserts until ~9,600 quota units or quotaExceeded, saves every 20
  4 verifies item counts against YouTube, writes datos\reportes\<fecha>.html, toast that opens the report
  Flags: --plan (offline) --simular --solo 154 152 --max 20 --silencioso
  datos\aprobado.flag: empty file = work on everything. A line "solo: 154" restricts a test to those lists.
  Nothing is ever deleted or unliked. Failed videos (deleted/private) go to progreso.json "fallidos" and the report.
