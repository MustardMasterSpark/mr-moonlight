1. WHAT CHANGED (why this is a Sonnet job now)
===========================================================================
Trees no longer get convex hulls. Each tree gets ONE non-convex MeshCollider built from the
triangles Carlos painted as wood, on a child `Visual/WoodCollider`. It's exact by construction
(Carlos's bar: a shot through visible air must never hit a collider). There's no geometry
algorithm left to tune: the tool is mechanical and it proves itself with raycasts.
Tool: Assets/_Project/Code/Editor/Migration/WoodColliderTool.cs
Do NOT use TreeColliderTool / LimbSegmenter / MeshCoverField for static trees - superseded.

===========================================================================
2. THE RUN (per batch)
===========================================================================
Close Prefab Mode first (the tool refuses a prefab that is open in a stage). Call by reflection
from execute_code (CodeDom C# 6):

  System.Type t = null;
  foreach (var a in System.AppDomain.CurrentDomain.GetAssemblies()) { var tt = a.GetType("MrMoonlight.EditorTools.Migration.WoodColliderTool"); if (tt != null) { t = tt; break; } }
  string[] names = (string[])t.GetMethod("PaintedPrefabs").Invoke(null, null);   // or an explicit list
  try { return t.GetMethod("Run").Invoke(null, new object[] { names, true }).ToString(); }   // dry run
  catch (System.Reflection.TargetInvocationException e) { return "ERROR: " + e.InnerException; }

Order:
 1. Dry run -> open EVERY Temp/TreeColliders/<prefab>_wood.png (Read tool). Left = whole mesh,
    painted wood orange, the rest grey. Right = the collider. A GREY limb thick enough to hide
    behind = a missed branch -> list it for Carlos; don't decide yourself.
 2. Real run: Run(names, false). Every line must say VERIFY OK.
 3. RayTest(names, 3000). Every line must say RAYTEST OK (0 "collider hit, no wood",
    0 "wood, no collider hit").
 4. Update Docs/tree-collider-tracker.md (the wood-collider table). One line per tree.
 5. Carlos checks live. Only his OK moves a tree to Done.
Runs are fast (5 trees: a few seconds). If something takes over a minute, stop and report - the
old hull tool once froze the Editor for 13 minutes.

4. TRAPS
===========================================================================
- After every script compile, the first execute_code returns {"success":false,data:null}. Send a
  throwaway `return "ping";` first. A long call can also return that while Unity is still working:
  check the report file's timestamp (Temp/TreeColliders/wood_run.txt) before re-running.
- Two-sided: triangles whose material has Retro Lit `_Cull` == 0 get a reversed twin (physics
  ignores back faces; DeadTree01 lost 13/558 test shots through mesh holes without it). Culled
  materials stay one-sided on purpose. If a new shader shows up without `_Cull`, it's treated as
  one-sided: say so in the report.
- The report's "submesh 0: N/M painted" is a hint, not a pass/fail (leaf cards and moss often
  share the bark submesh). The image decides.
- The collider child copies Visual's layer + tag (physics reads the collider's OWN tag).
- The test copies only. Nothing is carried over to live vegetation prefabs / Island yet - that's a
  separate, unwritten step. Don't start it without Carlos.
