SUMMARY (the title field in GitHub Desktop)
===========================================

MRM-86: Weather profiles (sky, sun, ambient, special lights, HAZE fog) + Lighting Test Scene with a blend circuit


DESCRIPTION (the body field)
============================

First two steps of the MRM-86 lighting/weather rework, built only in a new test scene. Nothing in Island or
Island_Legion changes behaviour; the old SUN / TimeManager / SkyboxSwitcher / HAZE objects there are untouched and get
replaced in a later step, once Carlos decides how the profiles are wired into the game.

Weather profiles
- NEW Data/Weather/WeatherProfiles.asset (WeatherProfileLibrary): 27 profiles, one per story part and Legion act,
  titled "Story 1 · Campsite" ... "Legion W7 A2 · Conflict". Each holds Sky, Sun (direction, colour/temperature,
  intensity, indirect, shadows), Environment (ambient source/colours/intensity, reflections), "* Special light
  sources" (Lamps, Flares, Moon Glow, each with an Override switch; off = prefab values; the player's two lights will
  join this group later) and Fog (HAZE global, noise/scattering, area box; HAZE-shaped, may change if we move to
  Volumetric Fog & Mist 2). All start at clean defaults: Unity's sun/ambient, HAZE's fog.
- WeatherSystem blends everything with one 0-1 value, applies live edits to the current profile section by section,
  and saves the live SUN/ambient ("Save Lighting Values") or fog ("Save Fog Values") into it (editor Play Mode only).
- HazeFogAdapter is the only HAZE-aware code; WeatherLightSource marks world lights by category.
- WeatherTuningPanel: P opens the bottom-right panel with the two Save buttons (frees the mouse); a status line and
  key reminder stay on screen.

Lighting Test Scene
- NEW Scenes/LightingTestScene.unity: a copy of Island_Legion (trees, terrain, Spotters) with TimeManager,
  SkyboxSwitcher and Scene Effects Toggle removed from the copy, its own fog profile (VP_LightingTest_Fog), and the
  sun/ambient/fog reset to defaults.
- SkyProximityCircuit: a yellow cylinder (no collider) on one corner of a 22 m square 58 m south of the Glade. Inside
  the pink sphere (8 m) the weather blends toward the cylinder's profile; at the green sphere (2 m) it locks and the
  cylinder moves clockwise to the next profile. Loops all 27.
- SkyBlender cross-fades skies with AST-054's blend shader on a runtime material copy, and snapshots the starting sky
  with a sky-only camera (realtime reflection probes are off in Quality settings).
- DevTools/EnemyVisibilityToggle: O hides every enemy and pauses spawning; O again restores the same enemies.

Assets and shared code
- NEW AST-271 Draw Debug Tools v3.0, tracked at Code/Vendor/AST-271 Draw Debug Tools/ (debug camera key moved F9 ->

  local orientation edit). NEW Art/Environment/Skies/M_Sky_Blend.mat.
- Prop_Lamp (and so every Spotter lamp), VFX_Flare, Prop_Moon: a WeatherLightSource marker, inert without a

- MrMoonlight.Runtime.asmdef references DrawDebugTools and Haze.Runtime.
- MoonlightTunables: SkyBlend* (radii, sphere look, capture resolution) and WeatherAmbientRefreshSeconds.
