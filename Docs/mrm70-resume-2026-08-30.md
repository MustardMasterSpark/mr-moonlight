## Where things stand

**Vegetation asset prep is done.** 158 species (137 built + 21 `RF_*`) exist as prefabs with the
standard parent+`Visual` structure, standardized scale/pivot (Carlos hand-corrected all sizing and
pivots himself against the player's own scale), and now colliders on every one of them:
- 154 `AP_*`/`RF_*` species from the original batch got their first colliders this session (81
  freshly resized/re-pivoted ones got capsule/box colliders built from real mesh geometry; some
  `RF_*` ones — `RF_Stump1`/`RF_Stump2` — got hand-calibrated capsule colliders as a technique
  proof before the batch, see the handoff doc's collider section for the exact method).
- Capsule colliders span each prop's **full** mesh height (below-ground root to canopy top) with a
  radius sampled from the actual trunk geometry — **not** tapered, not clamped to player height;
  see the handoff doc for why and the one thing worth knowing (a capsule can't taper, so it's
  effectively a thin pole running the full height on tall trees — intentional, canopy is meant to
  be walk-through).
- A real, separate bug was found and fixed along the way: many foliage "card" planes (single-sided
  quads standing in for canopy) were invisible from behind due to shader backface culling. Fixed at
  the material level (96 → corrected down after two rounds of over/under-scoping — see the handoff
  doc's "foliage-card materials" sections for the full, slightly bumpy history, worth reading before
  assuming any given material's `_Cull` value is right).

**Carlos's own words this session: "our assets are ready."** Don't second-guess this — the next
session's job is placement, not more prep.

**`VegetationGallery` now has a lighting/fog/CRT preview rig**, so trees can be inspected under real
conditions instead of flat ambient light: `SkyboxSwitcher` + `TimeManager` prefabs (wired to the
gallery's own `SUN`), Island's `HAZE Global Fog` + `HAZE Explorable Area Fog` (cloned, then resized
to the gallery's own footprint — NOT Island's terrain-scaled transform), and the `Scene Effects
Toggle` prefab (wired to the gallery's own fog Volume) so fog/CRT can be flipped off while staging.
**Gallery still uses its own simple `Ground` plane — Island's real terrain/Gaia/Crest water were
deliberately NOT brought in**, Carlos declined those explicitly. Full detail in the handoff doc's
"lighting/fog/CRT preview systems" section — **read the shared-state gotcha there before touching
`Scene Effects Toggle` again**: its checkboxes edit the shared `VP_HazeGlobalFog` profile asset
directly (same one Island uses), not a local override. It was left at ship defaults (fog+CRT on)
this session; if a future session finds it off, someone forgot to run "Restore Ship Defaults" and
Island has been quietly running fogless/CRT-less too.

## Resolved this session: Burntwax's script logic is now tracked

Was flagged as a gap earlier this session (Burntwax lived entirely under the git-ignored
`Assets/ThirdParty/`, so the super-jump code fixes couldn't be committed). Carlos's call: vendor
**script logic** we actually edit should be tracked; vendor **3D/binary content** should stay
git-ignored. Burntwax's whole `Scripts/` folder (asmdef + all 62 `.cs` files, including
`PlayerStateMachine.cs`) was moved — via `AssetDatabase.MoveAsset`, GUIDs preserved, verified —
from `Assets/ThirdParty/Burntwax Collective/Burntwax FPS Engine/Scripts/` to
**`Assets/_Project/Code/Vendor/Burntwax FPS Engine/Scripts/`**, which IS tracked. The super-jump
fixes are committable for the first time as of this session. Policy is now written into
`Docs/unity-conventions.md` (folder-structure section) and [[thirdparty_gitignored]] — apply the
same move to any *other* vendor package once its scripts are being edited non-trivially, but don't
retroactively sweep every already-integrated package now.

**One pre-existing, unrelated thing turned up while verifying the move (not caused by it):** 21
GameObjects across the project have a missing-script component — all on Burntwax's own unused demo
prefabs (`Prefabs/Environment/...` pickups/crate/target), a few obviously pre-existing scratch/
legacy prefabs (`DefenseTest`, `MeleeTest`, `PitchTest`, `Player_Legacy_PreMRM9`), Gaia's Photo
